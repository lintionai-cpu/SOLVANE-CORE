    Connection PAT / OTP
    Remember token on this device
    Off by default. If enabled, the PAT is written to localStorage and survives reloads — only enable on a device you trust, never on a shared/public machine.
    With a PAT: fetches your account list → requests a short-lived OTP → opens an OTP-authenticated WebSocket (no legacy app_id query param, no authorize command). Without a PAT: connects to Deriv's public no-auth market-data socket. By default the token lives only in page memory for this tab and is cleared on reload — it is only written to localStorage if "Remember token" is enabled above. PAT/OAuth architecture notes: a PAT in a browser is inherently exposable via XSS; for a publicly distributed app, OAuth 2.0 + PKCE with server-side token exchange is the recommended architecture instead.
